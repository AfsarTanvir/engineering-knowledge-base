* Document concepts I learn from books, official documentation, technical articles, YouTube videos, courses, and AI-assisted study.
* Store code snippets, SQL queries, design patterns, and architectural diagrams.
* Record lessons learned while building real-world projects.
* Track my growth as a software engineer through continuous learning.
* Keep notes and references for interview preparation and solving practical engineering problems.
