# Networking

A learning track on computer networking — from first principles up
through the protocols that power the modern web. Each numbered folder is
one topic; add notes, diagrams, images, or scripts inside as needed —
this doesn't have to stay markdown-only.

## Roadmap

1. [Basics & Terminology](01-basics-and-terminology/) — client, host,
   server, packet, frame, and the vocabulary everything else builds on
2. [Network Devices](02-network-devices/) — hubs, switches, routers,
   modems, access points, firewalls
3. [TCP/IP](03-tcp-ip/) — the TCP/IP model, IP addressing, TCP vs UDP,
   ports, three-way handshake
4. [OSI Model](04-osi-model/) — the 7 layers, how they map to TCP/IP,
   encapsulation/decapsulation
5. [Core Protocols](05-core-protocols/) — ARP, DHCP, ICMP, DNS, NAT
6. [Application Protocols](06-application-protocols/) — HTTP/HTTPS, FTP,
   SMTP, SSH, WebSockets
